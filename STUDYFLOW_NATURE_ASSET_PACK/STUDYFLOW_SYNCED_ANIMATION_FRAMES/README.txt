STUDYFLOW SYNCED ANIMATION FRAMES

This pack contains 5 synchronized animation sets extracted from 4-frame sprite sheets.
Each set uses the same frame canvas size across all 4 frames so you can animate them smoothly in web UI.

Sets included:
- bunny
- fox
- bear
- owl
- bush

Frame specs:
bunny: 2172x724, frame=543x724
fox: 2172x724, frame=543x724
bear: 2172x724, frame=543x724
owl: 2172x724, frame=543x724
bush: 2172x724, frame=543x724

Each folder contains:
- <name>_sprite_sheet.png
- <name>_frame_1.png
- <name>_frame_2.png
- <name>_frame_3.png
- <name>_frame_4.png

Frames were split evenly from synchronized sprite sheets without trimming, to preserve alignment for animation.
